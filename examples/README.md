# Examples

Small, fast, self-contained scripts (a few seconds each):

| Script | Shows |
| --- | --- |
| `regression_quickstart.py` | correlated and duplicated predictors, random forest, RMSE |
| `classification.py` | binary and multiclass targets with probability-based scoring |
| `grouped_cv_pipeline.py` | `GroupKFold`, a `Pipeline` estimator, feature subsets, the stand-alone residualizer |

Run with `python examples/<script>.py`. Paper-scale benchmarks live in the
separate `sharedimp-experiments` repository.
